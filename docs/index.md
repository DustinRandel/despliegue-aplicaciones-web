# Despliegue de aplicaciones web

Apuntes y prácticas del módulo **Despliegue de aplicaciones web**, de <u>2º de DAW</u>.

En este módulo vas a aprender qué ocurre con una aplicación web **después** de programarla:
dónde se pone para que el mundo la use, cómo se configura la máquina que la sirve, cómo se
protege, cómo se versiona el código y cómo se automatiza todo el proceso.

## Contenidos

1. **Introducción** — el escenario del despliegue: VPS, máquinas virtuales y SSH
2. **Arquitectura web** — implantación y administración de servidores web
3. **Servidores de aplicaciones**
4. **Servicios de red** implicados en el despliegue: DNS
5. **Control de versiones** — Git y GitHub
6. **Contenedores** — Docker
7. **CI/CD** — integración y despliegue continuo

!!! tip "Cómo se trabaja en este módulo"
    Apenas trabajarás en tu propio ordenador. Todo ocurre sobre una **máquina virtual** que
    simula un servidor remoto, a la que te conectarás por **SSH**, igual que se hace en la
    vida real. El [Tema 1](T1-introduccion.md) explica por qué.
